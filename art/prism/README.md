# Prism artwork

Official marks for **Prism**, Almasix’s view engine — geometry from the
approved icon, colored with the Almasix brand palette.

| File | Use |
|------|-----|
| `prism.svg` | Full-color mark (docs, marketing, transparent) |
| `prism-icon.svg` | App / marketplace tile (rounded dark ground; lighter prism) |
| `prism-file.svg` | Editor file icon for `.prism.html` (32×32) |
| `prism-mono.svg` | `currentColor` silhouette for chrome / dark mode |

**Colors**

- Prism body: `#286291` (apex lifts to `#3D7EB0`; dark-tile mark uses `#6BB0D9` → `#3D7EB0`)
- Incoming beam (through the glass): `#F1511B` / `#FF7A4D`
- Spectrum: coral → amber → teal

Copies also live under `website/public/` and `website/src/assets/`. Editor
packaging belongs in
[`almasix-dev/ide-support`](https://github.com/almasix-dev/ide-support).
