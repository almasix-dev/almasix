The **almasix-inertia** package has its own documentation site:

**[inertia.almasix.com](https://inertia.almasix.com/)**

Install with `pip install 'almasix[inertia]'` (or `almasix-inertia`). Use the
official `@inertiajs/vue3`, `@inertiajs/react`, or `@inertiajs/svelte` clients —
there is no forked JS client.

SPA starter kits register the adapter automatically; see
[Starter kits](/starter-kits/).
