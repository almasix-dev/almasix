## Meet Almasix

Almasix is a Python web framework with expressive structure and first-class
`async`/`await` for ASGI. Create applications with `almasix new`, then drive them
with **Smith** — Almasix’s in-app CLI:

```bash
almasix new blog
cd blog
smith serve
```

Templates, routing, validation, localization, and the ORM all live behind the
`almasix.*` package. You write application code; Almasix boots the container,
compiles your routes, and serves them over ASGI.

:::note
Almasix is inspired by Laravel’s application shape. The public APIs, CLI, ORM,
and view engine are Almasix’s own — **Smith**, **Articulate**, and **Prism**.
:::

## Requirements

- Python **3.11** or higher
- `pip` and a virtual environment
- Node.js **18+** (optional but recommended) for the default Vite + Tailwind toolchain

## Creating an Almasix project

<Steps>

1. **Install Almasix** (from PyPI, or from a local checkout while developing against main):

   ```bash
   pip install almasix
   # or, from a local clone of the framework:
   pip install -e /path/to/almasix
   ```

2. **Create a new application:**

   ```bash
   almasix new blog
   cd blog
   ```

3. **Create a virtual environment and install dependencies:**

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e .                 # your app
   pip install almasix               # or -e /path/to/almasix during local development
   ```

4. **Install frontend dependencies (Vite + Tailwind):**

   ```bash
   npm install
   ```

5. **Start the development server:**

   ```bash
   smith serve
   ```

   Visit the URL Smith prints (typically `http://127.0.0.1:3000`). In another
   terminal, run `npm run dev` while iterating on CSS/JS.

</Steps>

:::tip[Smith]
With the virtualenv active, Almasix installs a `smith` console script — run
`smith serve`, `smith migrate`, `smith loupe`, and so on. The root `smith`
file still works as `python smith …` if you prefer that form.
:::

## Directory structure at a glance

A fresh application looks like this:

```text
blog/
  app/
    http/controllers/
    models/
    providers/
  bootstrap/app.py
  config/
  database/migrations/
  database/seeders/
  resources/css/
  resources/js/
  routes/web.py
  routes/api.py
  package.json
  vite.config.js
  smith
```

Read more in [Directory Structure](/structure/) and [Asset Bundling](/asset-bundling/).

## Database drivers

SQLite works out of the box. For other engines, install the matching optional extra:

```bash
pip install almasix[pgsql]    # PostgreSQL
pip install almasix[mysql]    # MySQL / MariaDB
pip install almasix[sqlsrv]   # SQL Server
pip install almasix[oracle]   # Oracle (optional)
pip install almasix[db]       # all of the above
```

Configure connections in `config/database.py` — see [Database: Getting Started](/database/).
